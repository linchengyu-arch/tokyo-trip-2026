## App 功能

- 每日詳細時間／交通／餐飲／預算
- 景點、早餐、午餐、晚餐、交通、購物分類
- Google Maps 現在位置導航
- 固定預約清單與下一站倒數
- 行程完成打勾與旅程進度
- 每日支出紀錄
- 雨天備案
- 票券／訂位截圖本機保存
- PWA / 離線使用 / 加入手機主畫面
